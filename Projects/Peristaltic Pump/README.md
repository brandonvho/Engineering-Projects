# Peristaltic Pump 
 
## Overview 
I will be trying to create a peristaltic pump using an arduino, a stepper motor, and a 3D printer.

## Objectives 
- To learn circuit design.
- To learn how to program an arduino.
- To learn how to program a stepper motor.
- Create a working peristaltic pump that will transfer liquids from one container to another.
- Figure out the stepper motors ability to dispense desired volume.
 
## Requirements & Constraints 
- Using an arduino mega kit, 3D printer, and some amazon products.
 
## Design Summary 
The stepper motor and circuits will be inside a 3D printed housing. There will be an LCD screen to view a menu, and a keypad to type in volume and change units. I will be using ball bearings to roll and compress a flexible tube, creating a vacuum that draws liquid in and pushes it out.
 
## Tools & Technologies 
- CAD: Fusion
- Electronics (if any): Elegoo mega controller board, LCD1602 Module, nema17 stepper motor, membrane switch module, power supply module, 12v power supply, ...
- Manufacturing: Bambu Lab P1S
- Software: Arduino ide
