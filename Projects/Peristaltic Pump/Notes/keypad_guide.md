# Keypad Guide

## Layout

```
[ 1 ] [ 2 ] [ 3 ] [ A ]  ← decimal point
[ 4 ] [ 5 ] [ 6 ] [ B ]  (unused)
[ 7 ] [ 8 ] [ 9 ] [ C ]  (unused)
[ * ] [ 0 ] [ # ] [ D ]  (unused)
  ↑               ↑
clear          confirm
```

## Entering a Volume

1. Type your desired volume in mL using the number keys — up to **999.9 mL**.
2. Press **`A`** to insert a decimal point (e.g. `2` → `A` → `5` gives `2.5`).
3. Press **`#`** to confirm and start dispensing.

The LCD will show your input on the second line as you type, and switch to a live progress percentage once dispensing begins.

## Key Reference

| Key | Action |
|-----|--------|
| `0`–`9` | Enter digits |
| `A` | Insert decimal point (only one allowed) |
| `#` | Confirm volume and start dispensing |
| `*` | Clear input **or** emergency stop mid-dispense |

## Notes

- Maximum input is **5 characters** (e.g. `999.9`).
- If you enter `0` or leave the field blank and press `#`, nothing happens.
- If you exceed 999.9 mL the LCD will show a "Bad volume!" error — press any key to dismiss and re-enter.
- `B`, `C`, and `D` are not assigned yet.
