# Sensor Cover 
 
## Overview 
My friend asked me if I could create something to cover a sensor hole on his car.
 
## Objectives 
- Create a piece that can pop into the sensor hole and fit snug.
 
## Requirements & Constraints 

 
## Design Summary 
Circular clip similar to car push clips.
 
## Tools & Technologies 
- CAD: Fusion
- Manufacturing: Bambu Lab P1S
 
## Testing & Results 
- First piece was too thin and broke easily. It also did not fit tight, so it was easy to remove.
- Next prototype used a larger diameter for the overhang and thicker walls.
 
## Challenges & Lessons Learned 
When slicing, it was not getting the thin parts, and I had to open the advanced settings to allow thin wall detection.
 
## Future Improvements 
I told my friend to try it out and if he had any problems then I can try to improve the design.
